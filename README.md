# 弹幕地狱 · DANMAKU HELL

> 线上地址：**https://yjj0339.github.io/danmaku-hell2/** （手机可直接扫码打开）

浅色 CRT 风格纵版弹幕射击。连破三角、六边、圆环三位 Boss，每位三阶段变换弹幕；擦弹加分，炸弹清屏。

## 玩法

- **移动**：方向键 / WASD（`Shift` 慢速微调）· 手机拖动屏幕任意位置（相对拖动，手指不挡飞船）
- **炸弹**：`X` / `空格` · 手机双击 —— 清除全屏子弹，击破 Boss 补充 1 颗
- **擦弹**：飞船中心是小判定点，贴着子弹飞过每发 +10 分
- **三残机起步**，连续击破三位 Boss 即通关；66% / 33% 血量时 Boss 切换攻击模式

| Boss | 外观 | 弹幕 |
|---|---|---|
| 棱光三角 TRI-PRISM | 粉色三角 | 旋转螺旋 · 自机狙 · 环形 · 花形 |
| 蜂核六边 HEX-CORE | 紫色六边 | 花形 · 旋转环 · 大弹狙击 |
| 终焉圆环 OMEGA-RING | 橙红圆环 | 环形 · 天降弹墙 · 四臂螺旋 · 花形 |

## 技术

- 纯 Canvas 2D + Web Audio 合成音效，零外部素材、零依赖
- 子弹预渲染发光贴图（径向渐变 + 暗描边 + 高光），三种弹型精灵缓存
- IndexedDB 保存最高分（localStorage 兜底）
- CRT 扫描线 / 滚动亮带 / 四角晕影用 CSS 叠加层实现，不吃游戏性能
- 自适应任意窗口尺寸，手机竖屏适配（`pointer:coarse` 自动切换操作提示）

## 本地运行

```
node tools/server.js   # http://127.0.0.1:8077/
```

## 调试参数

| 参数 | 说明 |
|---|---|
| `?seed=N` | 固定随机种子（可复现弹幕） |
| `?ts=N` | 时间倍速（0.2–6） |
| `?god=1` | 无敌模式 |
| `?auto=1` | AI 自动躲避试玩 |
| `?dmg=N` | 自机弹伤害倍率（平衡测试用） |

`tools/verify.js` 全流程自动化验收（Playwright）：13 项流程断言 + 手机触控模拟 + AI 平衡试玩。
